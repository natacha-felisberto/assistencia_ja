# assistencia_ja
Plataforma web e mobile para solicitação e gerenciamento de serviços de assistência residencial.


# 🏠 Plataforma de Assistências

Plataforma desenvolvida como **projeto de portfólio**, com o objetivo de aplicar na prática conceitos de desenvolvimento de software, desenvolvimento web e desenvolvimento mobile.

A proposta é criar uma solução que facilite a solicitação e contratação de **serviços de assistência residencial**, conectando clientes a prestadores de serviços de diferentes áreas.

O projeto será composto por uma **plataforma web** e um **aplicativo mobile**, permitindo que clientes solicitem assistência de forma rápida e que prestadores recebam, acompanhem e aceitem solicitações diretamente pelo celular.

> **Importante:** este projeto possui finalidade educacional e de portfólio. Não possui finalidade comercial neste momento.

---

## 📌 Sobre o projeto

A ideia surgiu a partir de uma situação comum: quando alguém precisa resolver um problema em casa, muitas vezes não sabe qual profissional procurar, onde encontrá-lo ou como solicitar o atendimento.

A plataforma busca centralizar esse processo em um único ambiente, permitindo que o cliente encontre uma assistência adequada e que o prestador tenha uma forma prática de receber e gerenciar seus atendimentos.

Entre os serviços que poderão fazer parte da plataforma estão:

* 🔌 Eletricista
* 🚿 Encanador
* 🧊 Manutenção de geladeira
* 🧺 Manutenção de máquina de lavar
* ❄️ Manutenção de ar-condicionado
* 🏊 Limpeza e manutenção de piscina
* 🧹 Serviços de limpeza
* 🎨 Pintura
* 🔨 Pequenos reparos
* 🌱 Jardinagem

A lista de categorias poderá ser modificada durante o desenvolvimento.

---

## 📱 Plataforma Web + Aplicativo Mobile

O projeto será desenvolvido para funcionar em diferentes ambientes.

### 💻 Plataforma Web

A versão web será utilizada principalmente para:

* Apresentação da plataforma;
* Cadastro e gerenciamento de usuários;
* Consulta de serviços e prestadores;
* Solicitação de assistência;
* Gerenciamento de atendimentos;
* Administração da plataforma.

### 📲 Aplicativo Mobile

Também será desenvolvido um aplicativo para dispositivos móveis utilizando **React Native**.

O aplicativo terá como objetivo tornar a solicitação e o gerenciamento de assistências mais rápidos e acessíveis.

Para o cliente, o aplicativo permitirá, entre outras funcionalidades:

* Solicitar uma assistência diretamente pelo celular;
* Informar rapidamente um problema;
* Acompanhar solicitações;
* Consultar agendamentos;
* Receber atualizações sobre o atendimento.

Para o prestador, o aplicativo poderá permitir:

* Receber novas solicitações;
* Ser acionado rapidamente quando houver um serviço compatível;
* Aceitar ou recusar atendimentos;
* Acompanhar sua agenda;
* Consultar informações do cliente e do serviço;
* Atualizar o status do atendimento.

A definição das funcionalidades do aplicativo será refinada durante o desenvolvimento.

---

## 🎯 Objetivo

Desenvolver uma solução web e mobile que permita praticar, de forma integrada, diferentes etapas do desenvolvimento de software, desde o levantamento de requisitos e modelagem até a implementação, testes, documentação e publicação da aplicação.

O projeto também tem como objetivo demonstrar conhecimentos técnicos e boas práticas de desenvolvimento em um **portfólio profissional**.

## 👥 Perfis de usuário

Inicialmente, a plataforma será planejada considerando três perfis:

### 👤 Cliente

Poderá:

* Criar uma conta;
* Consultar tipos de assistência;
* Informar um problema;
* Informar localização;
* Buscar prestadores;
* Solicitar um atendimento;
* Agendar um serviço;
* Acompanhar solicitações;
* Consultar histórico;
* Avaliar o atendimento.

### 👨‍🔧 Prestador

Poderá:

* Criar um perfil profissional;
* Informar suas especialidades;
* Definir sua área de atendimento;
* Informar disponibilidade;
* Receber solicitações;
* Aceitar ou recusar atendimentos;
* Gerenciar sua agenda;
* Consultar histórico;
* Acompanhar avaliações.

### 👩‍💼 Administrador

Poderá:

* Gerenciar usuários;
* Gerenciar prestadores;
* Gerenciar categorias de assistência;
* Acompanhar solicitações;
* Gerenciar avaliações;
* Administrar informações da plataforma.
